Threshold and CSS Sets: Setting the Pace

Guide · Arman Sanei

What CSS Represents

Critical swim speed is the pace a swimmer can theoretically hold for a long time without lactate piling up faster than the body can clear it. It's not a lab number pulled from blood draws. It's a field estimate of aerobic threshold pace, built from two time trials your squad can do in a normal practice.

Physiologically, CSS sits close to the boundary between heavy aerobic work and the zone where lactate starts accumulating. Training at and around this pace builds the engine for everything from the 200 to the mile — better oxygen delivery, more efficient stroke mechanics under fatigue, and a pace the swimmer can trust when a race gets hard in the third quarter.

Testing CSS

The standard field test uses two time trials at different distances, swum all-out, ideally on separate days or with full recovery between them in the same session: a 400 and a 200.

Formula:

CSS (m/s) = (Distance2 − Distance1) / (Time2 − Time1)

Worked example:

  • 400 free time trial: 4:40 (280 seconds)
  • 200 free time trial: 2:10 (130 seconds)

CSS = (400 − 200) / (280 − 130) = 200 / 150 = 1.333 m/s

Convert to pace per 100: 100 / 1.333 = 75 seconds → 1:15 per 100

That 1:15 becomes the anchor pace for the next training block.

A few notes on the test itself:

  • Run it after a real warm-up, not cold.
  • Both swims need to be genuine efforts — a soft 400 followed by an all-out 200 will skew the number toward the 200 and inflate CSS.
  • Use the same stroke and course (SCY or LCM) you'll train in. Don't test long course and apply the pace to a short course pool without conversion.

Setting Send-Offs from CSS

Once you have CSS pace per 100, build send-offs around it rather than round numbers pulled out of the air.

  • Threshold reps with short rest: send-off = CSS pace + 10 to 20 seconds. For 1:15 CSS, that's 1:25–1:35 for 100s.
  • Broken or longer reps (200s, 300s): scale the rest proportionally — add 15–25 seconds per 200, 20–30 per 300.
  • Descending sets: start the send-off looser (CSS + 20–30) and tighten across the set as the swimmer works down to CSS pace on the last rep or two.

The send-off should force honest pacing — enough rest to hit the number, not so much that the set turns into a sprint-rest-repeat pattern.

Set Shapes

1. Long reps at CSS, short rest (aerobic threshold volume)

16 x 100 free @ 1:30 (CSS 1:15 + 15 rest) Hold 1:13–1:15 throughout. If a swimmer is at 1:18+ by rep 10, the send-off or the CSS number needs adjusting next time.

2. Descending to CSS

5 x 300 free @ 4:15 Descend 1–5, with #5 landing at or under CSS pace (3:45 for 300 at 1:15/100). This teaches pacing discipline — swimmers learn what "controlled" feels like versus "race pace," and the last rep confirms whether CSS is still accurate.

3. CSS +/- ladder

2 rounds of: - 200 @ CSS − 3 sec/100 (2:24) — send-off 3:00 - 200 @ CSS (2:30) — send-off 3:05 - 200 @ CSS + 3 sec/100 (2:36) — send-off 3:10

This set builds pace flexibility. Swimmers learn to go slightly faster than threshold without blowing up, and slightly slower without losing form — both useful skills in races where pace shifts lap to lap.

How Often to Retest

Retest every 4 to 6 weeks, or at these checkpoints:

  • End of a base/aerobic phase, before shifting to more race-pace work
  • After an illness or training break long enough to affect fitness
  • Before a taper, to confirm the pace you'll use for taper-phase quality sets

Don't retest more often than that. CSS doesn't move much week to week, and constant retesting eats into training time better spent on the sets themselves. If a swimmer is consistently hitting paces faster than CSS with rest to spare, that's a sign to retest early — the number is stale.

Why Threshold Work Is the Backbone

Middle-distance events — the 200 through the 1500/1650 — are won or lost on the ability to hold a fast aerobic pace under accumulating fatigue. Pure sprint work doesn't train that. Pure aerobic base work at easy pace doesn't either.

CSS sits right at the pace where aerobic capacity gets stressed and adapts — more capillary density, more mitochondria, better lactate clearance, and better economy at race-relevant speeds. For 200 and 400 swimmers, CSS sets are close to race pace itself. For 800/1500 swimmers, CSS work builds the base that sprint and pace-specific work later gets layered onto. Even sprinters benefit — CSS sets build the aerobic support system that lets them recover between rounds and hold technique deep into a 100.

It's the set type you can return to all season, adjusting volume and rest, without it ever becoming irrelevant to the athlete's events.
